## 📌 Overview

This section covers Bootstrap 5 form elements, inputs, layout structures, floating labels, input addons, checkboxes, radio toggles, range sliders, and client-side form validation.

## 📖 Module Breakdown

| Module | Core Concepts & Classes |
| :--- | :--- |
| **`01-forms`** | Foundational form markup, labels (`.form-label`), input controls, and assistive help text (`.form-text`). |
| **`02-form-control`** | Text inputs, passwords, textareas, file inputs, sizing modifiers (`.form-control-lg`, `.form-control-sm`), disabled/readonly states, and `.form-control-plaintext`. |
| **`03-checks-radios`** | Custom checkboxes (`.form-check-input`), radio groups, toggle switches (`.form-switch`), and inline layouts (`.form-check-inline`). |
| **`04-range`** | Range input slider component (`.form-range`) with custom thumbs, tracks, steps, and disabled states. |
| **`05-input-groups`** | Prepend and append text badges, icons, dropdowns, and buttons to input fields using `.input-group` and `.input-group-text`. |
| **`06-floating-labels`** | Floating placeholder labels that animate upward on focus or input using `.form-floating`. |
| **`07-form-layout`** | Multi-column form layouts using `.row`, `.col-*`, and gutter spacing (`.g-3`). |
| **`08-horizontal-forms`** | Aligning labels and inputs on the same horizontal plane using `.col-form-label` paired with the grid system. |
| **`09-auto-sizing-forms`** | Auto-fitting form controls based on content dimensions using `.col-auto`. |
| **`10-inline-forms`** | Responsive single-line compact inline forms utilizing flexbox row utilities. |
| **`11-form-validation`** | HTML5 validation states (`.was-validated`, `.is-valid`, `.is-invalid`), and custom feedback messages (`.valid-feedback`, `.invalid-feedback`). |
