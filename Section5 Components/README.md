## 📌 Overview

This section covers Bootstrap 5's interactive, modular UI components. It includes collapsible accordions, contextual alerts, notification badges, breadcrumb navigation, buttons, button groups, and component practice modules.

## 📖 Module Breakdown

| Module | Component & Features | Classes & Notes |
| :--- | :--- | :--- |
| **`01`** | **Accordion** | Collapsible content panels with smooth transitions using `.accordion`, `.accordion-item`, `.accordion-header`, `.accordion-button`, and `.accordion-collapse`. |
| **`02`** | **Alerts & Links** | Contextual alert banners (`.alert-primary`, `.alert-success`, `.alert-danger`, etc.) featuring matching styled links (`.alert-link`). |
| **`03`** | **Dismissible Alerts** | Alerts that close on user click with fade animations via `.alert-dismissible`, `.fade.show`, and `.btn-close`. |
| **`04`** | **Badges** | Inline notification counts, heading tags, contextual background badges, and rounded pill tags (`.badge`, `.bg-*`, `.rounded-pill`). |
| **`05`** | **Breadcrumbs** | Hierarchical page navigation trails with `.breadcrumb` and `.breadcrumb-item.active`. |
| **`06`** | **Buttons & Grids** | Contextual buttons (`.btn-*`), outline buttons (`.btn-outline-*`), button sizes (`.btn-lg`, `.btn-sm`), and full-width block buttons via grid utility (`d-grid gap-2`). |
| **`07`** | **Button Groups** | Joining multiple buttons into a single horizontal segment using `.btn-group`. |
| **`08`** | **Button Toolbar** | Combining multiple button groups and input controls into complex toolbars using `.btn-toolbar`. |
| **`09`** | **Button Group Sizing & Vertical** | Sizing variations (`.btn-group-lg`, `.btn-group-sm`) and vertical stacking (`.btn-group-vertical`). |
| **`10`–`26`** | **Practice Modules** | Additional component practice covering Cards, Carousels, Dropdowns, List Groups, Modals, Navbars, Offcanvas, Pagination, Spinners, Toasts, and Tooltips. |

## 🚀 How to Run

Open any component folder (e.g., `Section5 Components/01/index.html` or `06/button.html`) in VS Code and view in browser using Live Server.
