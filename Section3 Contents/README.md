## 📌 Overview

This section demonstrates Bootstrap 5 typography rules, standard text formatting, responsive images, blockquotes, styled lists, data tables, and figure captions.

## 📖 Module Breakdown

| Module | Core Concepts & Classes |
| :--- | :--- |
| **`01-typography`** | Headings (`<h1>`–`<h6>`), display headings (`.display-1` through `.display-6`), lead paragraphs (`.lead`), and text color styling. |
| **`02-inline-text-elm`** | Native and styled inline text elements: `<mark>`, `<del>`, `<s>`, `<ins>`, `<u>`, `<small>`, `<strong>`, and `<em>`. |
| **`03-blockquotes`** | Styling quotations using `.blockquote`, attribution footers with `.blockquote-footer`, and `<cite>` tags. |
| **`04-lists`** | Unstyled lists removing bullets/margins (`.list-unstyled`), and horizontal inline lists (`.list-inline`, `.list-inline-item`). |
| **`05-images-in-bootstrap`** | Responsive fluid images (`.img-fluid` with `max-width: 100%; height: auto;`), image thumbnails (`.img-thumbnail`), and alignment utilities (`.float-start`, `.float-end`, `.mx-auto .d-block`). |
| **`06-tables-in-bootstrap`** | Standard `.table`, striped rows (`.table-striped`), hoverable rows (`.table-hover`), borders (`.table-bordered`, `.table-borderless`), dark theme (`.table-dark`), and `.table-responsive` wrappers. |
| **`07-table-alignment-nesting`** | Cell content vertical alignment (`.align-middle`, `.align-top`, `.align-bottom`) and embedding nested tables within table cells. |
| **`08-figures-in-bootstrap`** | HTML5 figure elements styled with Bootstrap figure helpers: `.figure`, `.figure-img`, and `.figure-caption` (including text alignment). |
